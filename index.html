Architecture

Built for execution, not passive checklists.

Every subsystem is engineered around native Android APIs so QuotaFolio stays fast, offline-first, and resilient across Doze mode, reboots, and timezone shifts.

ALARMCLOCK API

Doze-Proof Pop-Up Engine

Schedules exact triggers using AlarmManager.setAlarmClock. Pops straight over active apps or lock screens, falls back to high-priority full-screen intents, and auto-restores after reboot.

5-TABLE ROOM SQLITE

Non-Destructive Telemetry

Separates files, versioned schedules, immutable session logs, frozen daily targets, and manual bookmark audits. Editing quotas or jumping pages never erases past history.

ISOLATED STORAGE

Private Offline Library

Imported files are copied into internal app storage. Moving or deleting the original download in your file manager will never break your scheduled books or bookmarks.

ZERO-LAG READER

Persistent PDF & Text Cache

Keeps a single thread-safe PdfRenderer session open with 1.0x–3.5x pinch-to-zoom and pan, while text formats parse once per session with instant A- / A+ font sizing.

HONEST HABITS

Clean Skip Without Penalty

Busy when a slot fires? Tap Skip Slot to record 0 units transparently while preserving your exact bookmark—preventing dishonest check-offs or broken tracking.

BUILT-IN DIAGNOSTIC

10-Second Pop-Up Tester

Verify OEM battery and background permissions in 10 seconds from the in-app guide instead of waiting for a real schedule to discover a blocked alarm.

Offline Parsers

12 Supported File Format Families

All parsing happens natively on-device with zero third-party cloud converters or bloated libraries.

Extensions Rendering Mode Unit Counting Best Use Case
.pdf Full visual pages + 1.0x–3.5x pinch-to-zoom & pan Exact PDF page count Textbooks, biology/anatomy diagrams, formatted slides
.png .jpg .jpeg .webp Full visual chart + 1.0x–3.5x pinch-to-zoom & pan 1 visual chart (OOM-safe decode) Formula sheets, anatomy charts, mind maps
.epub Dark-mode book text (true OPF spine chapter order) + A-/A+ ~1,400 chars / page DRM-free non-fiction and novels
.docx .odt Dark-mode text (native OOXML / OpenDocument XML) + A-/A+ ~1,400 chars / page Study guides, essays, lecture notes
.pptx .odp Slide-by-slide text extraction + A-/A+ Exact slide count / pages Text-focused lecture decks
.rtf .html .htm Cleaned dark-mode text (strips tags/styles/metadata) + A-/A+ ~1,400 chars / page Saved offline articles and rich-text notes
.txt .md .csv .json Plain / structured dark-mode text + A-/A+ ~1,400 chars / page Vocabulary lists, Markdown notes, flashcards
Honest Format Limitations: Embedded illustrations and complex tables inside .docx, .pptx, and .epub render as text-only—export diagram-heavy Word or PowerPoint files to .pdf for full visual fidelity. Pre-2007 binary .doc/.ppt files and DRM-locked Kindle (.mobi/.azw3) or password-protected PDFs are not supported.
